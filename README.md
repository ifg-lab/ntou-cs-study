# 海洋大學計算機概論網站

**[直接進網站複習](https://ifg-lab.github.io/ntou-cs-study/)**

這是給修海洋大學計算機概論的同學用的複習站。可以照老師的投影片讀，練自己讀到的範圍，考前再拿歷屆原題試做一遍。免登入就可以看教材和做題。

## 從哪裡開始

- **課程目錄**有 8 章。Chapter 0～5 的教材已上架，依序是概論、資料儲存、資料操作、作業系統、電腦網路和演算法。Chapter 6「程式語言」與 Chapter 7「資料抽象」可以先開老師的講義 PDF 或看相關考古題。
- **接著讀**會帶你回上次看的頁面。首頁也會顯示各章合計有幾題待回練，點進去就能挑章次。
- **搜尋**可以找講義、術語和互動實驗。記得頁碼的話，可以直接打 `p.38`。
- **網站造訪**在頂部導覽列顯示全站今日訪客與在線人數，按瀏覽器匿名計算。今日訪客在台灣時間午夜重計，在線數依最近兩分鐘內的活躍瀏覽器估算。

## 看講義、做練習

- **逐頁教學**把老師的原投影片和中文解說放在同一頁。可以跳頁、放大或下載投影片、標記已讀、收藏或寫筆記。部分頁面有補充插圖或觀念小題，Chapter 4 和 Chapter 5 也可以開啟完整原投影片 PDF。
- **術語表**可以從講義上的術語點進去，看中英文名稱、詳細解釋、相關術語和原講義出處。複習重點有標示，部分詞條有例子和考題判斷方式。可以用中英文搜尋，按 A→Z、Z→A 或講義頁碼排序，再按章節、頁碼篩選，也能把複習重點置頂或只看重點。
- **互動實驗**可以自己改條件、逐步看結果。像是用二補數寫負數、看機器指令怎麼跑、讓兩個程序輪流用 CPU，或觀察交換器怎麼學來源 MAC。Chapter 4 還有一條從連上 Wi‑Fi 到開啟網站的複習路線，以及 Switch 和 Router 的轉送對照。
- **演算法互動**可以用自己的測資跑搜尋與排序、猜二元搜尋或 Kruskal 的下一步，也能編輯同一張地圖比較 BFS 和 DFS。播放器可快轉、倒回或逐步對照虛擬碼。
- **C++ 競程模板**收錄二元搜尋、前綴和、差分、雙指標、BFS、DFS、DSU 和快速冪等範例。程式可以複製或下載，附範例輸入輸出和可展開的繁中段落解說。
- **選擇練習**用英文出題，送出後會判分並顯示中文解析。可以按章節、觀念、頁碼或已讀範圍練習。答錯後可以回對應教材、做同觀念的互動實驗，或換一道同觀念的題目。把原題答對後，該題就會從待回練的錯題數扣除。
- **生成練習題**可以重複換題練二元搜尋、二補數和 IPv4 子網路。英文題目附繁中提示與解題步驟，判分在瀏覽器內完成。
- **AI 助教**在每頁教材標題下方，可開啟對話框請 AI 解釋、舉例或給提示。同一頁的對話會保留到重新整理或離開網站為止。也能選同一章內最多 5 頁生成英文情境題，作答後看繁中解析。全站共用每日 AI 額度，用完仍可繼續做計算練習。

## 考古題和模擬小考

- **考古題**從首頁進去可以按年份、場次翻原卷，也能搜尋考點。從 Chapter 4 的課程頁進去，就只會看到電腦網路相關的題目或小題。題目附原文、題號、配分、繁中詳解、參考答案和自評規準。
- **考點索引**把不同年份考過的相近觀念放在一起，可以回到原題對照。遇到霍夫曼樹、卡諾圖或程序切換等題目，也能用互動詳解一步一步看計算或流程。
- **模擬小考**可以做歷屆整卷或筆記重點混合卷。作答會保留草稿，交卷後可以看詳解並按給分點自評。想先練剛讀完的範圍，可以指定章次和頁碼，也可以只用已讀頁，網站會從有講義對照的原題出題。
- **考古題重做清單**可以從原題頁或交卷結果收錄整題或個別小題。下次從空白重新作答，練熟後可以標為已掌握。

## 複習紀錄

- **複習清單**可以集中看收藏的講義頁、術語、選擇題和自己寫的筆記，點回去就能接著讀或練。
- **學習紀錄**存在目前的瀏覽器。想把進度、答題紀錄和模擬卷草稿帶到另一台裝置，可以從「學習紀錄」匯出，再到另一台匯入。

登入、討論和跨裝置自動同步目前暫停開放。

## 外觀和閱讀設定

電腦在左下角開啟「設定」，手機從右上角的「更多」進入。可以切換淺色、深色和高對比主題，調整強調色、字級、行距和閱讀欄寬，也能選擇原投影片是否自動展開、怎麼和解說排列。做題時可以切換列表或一次一題，另外可調整答對音效和音量、關閉彩帶，或減少互動動畫。
